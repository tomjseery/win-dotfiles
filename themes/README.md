# Themes

Visual assets live here; their corresponding module owns installation.

- [Modern Office Pro](modern-office-pro/README.md): the existing blue folder artwork, cursor scheme, small Windows 11 glyphs and custom OneDrive variant.
- [Windows 11 drive icons](windows-11/README.md): the system/fixed drive icons.
- [Klassy caption glyphs](klassy/README.md): bold Traditional window controls.

Windows icons use `.ico` containers with several native resolutions. Cursors use
`.cur` and `.ani`. Original inputs and credits stay alongside each theme so the
custom variants can be rebuilt without finding files in Downloads or Pictures.
The full Windows visual-style package remains an external prerequisite.
